# Mini IP Manager

버튼 하나로 Windows 네트워크 설정을 **고정 IP(사내)** 또는 **자동 IP(외근, DHCP)**로 바꿔 주는 작은 앱입니다.
Windows 기본 PowerShell만 사용하므로 따로 설치할 프로그램이 없습니다.

## ⬇️ 다운로드

**[Mini-IP-Manager.zip 받기](https://github.com/hunykang/mini-ip-manager/releases/latest/download/Mini-IP-Manager.zip)**

(초록색 Code 버튼이 아니라 위 링크로 받으세요.)

## 설치 (처음 한 번)

1. 받은 zip 파일을 오른쪽 클릭 > **속성** > 아래쪽 **차단 해제** 체크 > 확인. 그다음 압축을 풉니다.
2. 압축 푼 폴더를 둘 곳에 두고(이후 옮기지 않기) **설치.cmd**를 더블클릭합니다. 바탕화면에 바로가기가 생깁니다.
3. 바탕화면의 **Mini IP Manager**를 더블클릭하고 관리자 권한(UAC)을 허용합니다.
4. 처음에는 고정 IP가 비어 있어서 등록 화면이 열립니다. 내 네트워크 어댑터를 확인하고 **내 고정 IP**를 등록합니다.
   - IP 주소, 서브넷 마스크, 기본 게이트웨이, 기본 설정 DNS, 보조 DNS (제어판 IPv4 속성과 같은 값)
   - 회사 자리에서 이미 고정 IP를 쓰고 있다면 **현재 설정 가져오기**를 누르면 채워집니다.

## 사용

| 누를 버튼 | 바뀌는 설정 | 그다음 |
|---|---|---|
| **고정 IP** | 기본값으로 지정한 IP·마스크·게이트웨이·DNS 2개 | 회사 Wi-Fi에 연결 |
| **자동 IP** | IP·DNS 자동으로 받기(DHCP) | 외부 Wi-Fi에 연결 |

- 고정 IP를 여러 개 등록할 수 있습니다. **고정 IP 관리** 화면에서 **기본값으로 지정**을 누른 항목이 **고정 IP** 버튼에 쓰입니다.
- 설정은 Wi-Fi 이름이 아니라 어댑터에 적용됩니다. 외근을 나가면 **자동 IP**를 눌러 주세요.
- 끄려면 화면 오른쪽 위 **끄기**를 누릅니다. 네트워크 설정은 그대로 유지됩니다.

## 업데이트

- 앱을 열 때 GitHub에 새 버전이 있는지 확인합니다. 새 버전이 있으면 화면 위에 **새 버전이 있습니다**가 뜹니다.
- **업데이트**를 누르면 받아서 설치하고 다시 시작합니다. 저장한 고정 IP(`config.json`)와 네트워크 설정은 그대로입니다.
- 버튼을 누르기 전에는 아무것도 받거나 바꾸지 않습니다. 화면 아래 **업데이트 확인**으로 직접 확인할 수도 있습니다.
- v1.0.0을 쓰고 있다면 이 기능이 없으니, 위 다운로드 링크로 한 번만 새로 받아 같은 폴더에 덮어쓰세요(`config.json`은 그대로 둠).

## 테스트할 때

- **자동 IP**는 어디서든 시험해도 됩니다.
- **고정 IP**는 회사 내부망에서 시험합니다. 회사 밖에서 누르면 인터넷이 끊기는데 정상입니다. **자동 IP**를 누르면 돌아옵니다.
- 앱이 안 열리면 Windows 설정의 IPv4 속성에서 **자동으로 IP 주소 받기**로 직접 되돌릴 수 있습니다.

## 실행 정책 때문에 막힐 때

설치.cmd가 "PowerShell scripts are blocked on this PC"라고 하며 이 README를 열었다면, 그 PC가 PowerShell 스크립트 실행을 막아 둔 상태입니다.

- **회사 PC:** IT 담당자에게 문의하세요.
- **개인 PC:** PowerShell을 열고 아래 명령으로 **내 계정만** 허용한 뒤 설치.cmd를 다시 실행하세요.

  ```
  Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
  ```

## 파일

| 파일 | 내용 |
|---|---|
| `MiniIpManager.ps1` | 로컬 웹 서버, IP 변경 처리(netsh) |
| `index.html` | 화면 |
| `설치.cmd` / `install.ps1` | 차단 해제, 바탕화면 바로가기 만들기 |
| `config.json` | 내 PC 설정(처음 저장할 때 생성, 다른 사람과 공유하지 않음) |
| `mini-ip-manager.log` | 변경 기록 |

웹 서버는 이 PC의 `localhost`에서만 열리며, 다른 웹사이트가 이 앱으로 요청을 보내지 못하도록 막아 두었습니다.
